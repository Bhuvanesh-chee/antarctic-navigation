Free-tier limitations
---------------------
- Sleeps after 15 minutes of no traffic. First request after sleep = 30-90s cold start.
- No uptime guarantee.
- Ephemeral disk: iceberg_catalog.db is re-seeded by entrypoint.sh on every boot
  (from bundled USNIC CSVs if present; otherwise synthetic/demo data).
- PORT must be set to 10000 in Render's environment variables, or the container
  will try to bind 7860 and Render won't reach it.

If the Render build fails
--------------------------
Check the Render build log:
- Dockerfile COPY paths: Dockerfile expects backend/, backend/requirements.txt,
  backend/entrypoint.sh, frontend/dist/ all at the repo root. If your repo
  nests these, fix Dockerfile COPY paths — do NOT move source files.
- frontend/dist/ must exist in the repo (it is committed). If missing:
    cd frontend && npm run build
    git add frontend/dist/ && git commit -m "rebuild frontend dist" && git push
- backend/requirements.txt must exist at backend/requirements.txt in the repo.
- backend/entrypoint.sh must be executable (Dockerfile does RUN chmod +x).

No tokens in files
-------------------
The space and origin remote URLs contain no token. If Git asks for GitHub
credentials during push, answer the prompt interactively — do not write the
token into .gitconfig, .git-credentials, any file, or the remote URL.
